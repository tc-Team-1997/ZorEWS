## Part 3 — Cross-cutting "addons" you must build alongside

Yeh sirf screens nahi hain — yeh **system-wide capabilities** hain jo poore application ke liye lagti hain. PDF mein in mein se kuch bhi nahi hai:

### 3.1 🌍 Multi-country regulator framework
- Country selector at login or in topbar
- Per-country SMA/NPA thresholds (RBI India: 30/60/90 DPD · RMA Bhutan: different · CBK Kenya: different)
- Per-country reporting templates
- Regulator master in Master Setup
- **Why critical:** A bank using ZorEWS in 3 countries shouldn't need 3 separate installations.

### 3.2 🏦↔️🛡 Banking / Insurance domain switch
- Topbar toggle: **BANK** ↔ **INSURANCE**
- Sidebar shows/hides relevant module group based on active domain
- Same code base, same masters, different operational screens light up
- **Why critical:** Aapke PDF mein Bank + Insurance dono ke masters hain, lekin **domain switching wiring** nahi hai.

### 3.3 🤖 AI / ML layer (deep, not just AI Workbench screen)
Wireframe mein **20+ screens pe `AI` tag** hai. Yeh sirf 1 AI Workbench page nahi hai — entire system AI-augmented hai:

| Where AI lives | Capability |
|---|---|
| Borrower Watch | AI risk score 0–100 |
| NPA Prediction | ML probability + AUC backtest |
| Lapse Risk, Claims Anomaly | ML models |
| Fraud Banking + Insurance | ML + network analytics |
| Data Profiling | Auto-suggest validation rules |
| Standardisation | Fuzzy matching |
| Anomaly Detection | Isolation Forest, 3σ |
| Validation Rules | AI explanation of rule failures |
| Underwriting Deviation | Deviation detection |
| Account Behaviour | Behavioural ML |

You need a **model serving layer** (FastAPI / gRPC microservice), **feature store**, and **model registry** to support all of this.

### 3.4 📡 Real-time pipeline
The wireframe assumes a streaming/near-real-time architecture:
- Kafka (or equivalent) for ingestion events
- Stream processor for live risk scoring
- Cache (Redis) for dashboard hot data
- Background workers (Celery / RQ) for batch jobs (nightly NPA, daily SMA, weekly sector refresh)

PDF mein "Schedule & Job Config" hai, but actual scheduler + worker runtime build karna padega.

### 3.5 📄 Regulator-specific exports
- CMA Pack PDF (Form II / III / IV / V) — for Indian banks
- IRDAI solvency returns — for Indian insurers
- Country-specific board pack templates

### 3.6 🔔 Notification execution
PDF mein "Notification Setup" config hai. But **actual email/SMS sending engine** (with templates, retry, delivery logs, opt-out) build karna padega.

### 3.7 📜 Audit Trail UI
PDF mein "Audit Config" + "Audit Administration" hai. But the **viewer UI** (filter who-did-what-when, export for regulator) is in the wireframe — pending.
