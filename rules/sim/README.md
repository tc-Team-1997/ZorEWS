# rules/sim/

Synthetic indicator history + simulator output for the rule engine.

## Files

- `indicator_history.csv` — generated by `npm run gen-history` (or `node scripts/run.js gen`). 250 customers × 12 months × 30 indicators with a labelled `defaulted_within_60d` column. Deterministic, seeded by `APEX_SIM_SEED` (default `20260426`).
- `report.json` — generated by `npm run simulate` (or `node scripts/run.js sim`). Per-rule stats: `total_firings`, `fp_rate`, `median_lead_time_days`, plus `mean_fp_rate` rollup.

## Regeneration

```bash
cd services/regulatory-svc/rules
npm install
npm run gen-history     # writes rules/sim/indicator_history.csv
npm run simulate        # writes rules/sim/report.json
# or, no-deps shim:
node scripts/run.js     # generates both
```

The harness was built without npm-install network access; `scripts/run.js` is a CommonJS mirror of the TS implementation that runs on stock Node.
