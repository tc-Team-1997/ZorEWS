**Phase:** T3-P4 (per [`docs/operationalization/execution-plans.md`](../../../docs/operationalization/execution-plans.md))

## Bootstrap sequence

```bash
# 1. Install ArgoCD via Helm chart (one-time)
helm repo add argo https://argoproj.github.io/argo-helm
helm install argocd argo/argo-cd \
  --namespace argocd --create-namespace \
  --values values-argocd.yaml

# 2. Apply the bootstrap Application (creates the parent app-of-apps)
kubectl apply -f bootstrap.yaml

# 3. ArgoCD auto-syncs the parent, which creates all child apps
argocd app list
# Should show: apex-ews-platform + 11 child apps (Healthy + Synced)
```

## Sync waves

Child Applications use the `argocd.argoproj.io/sync-wave` annotation to control order:

| Wave | Apps |
|---|---|
| 0 | platform-base (namespaces + RBAC + network policies) |
| 1 | external-secrets-operator (ESO must be ready before services) |
| 2 | ClusterSecretStore (creates the bridge to AWS Secrets Manager) |
| 3 | observability (Prometheus + Loki + Grafana — services need /metrics scraped) |
| 4 | auth-svc + audit-svc (no dependencies on other services) |
| 5 | regulatory-svc/{cases,alerts,rules,indicators} (depend on auth + audit) |
| 6 | bff (the API gateway — depends on every internal service) |
| 7 | collection-adapter + notification-svc + ai-copilot-svc (peripheral) |
| 8 | pipeline-svc (MWAA — last; needs everything else healthy) |

## Auto-sync policy

Every child Application uses:

```yaml
syncPolicy:
  automated:
    prune: true        # delete resources no longer in git
    selfHeal: true     # revert any out-of-band kubectl changes
  syncOptions:
    - CreateNamespace=true
    - PruneLast=true
    - ApplyOutOfSyncOnly=true
  retry:
    limit: 5
    backoff:
      duration: 30s
      factor: 2
      maxDuration: 5m
```

## Manual hot-fix flow (emergency only)

Per `docs/dr-runbook.md`, emergency hot-fix outside the PR-to-`main` flow requires:

1. CISO sign-off in `#apex-ews-incident`
2. ArgoCD app set to manual sync: `argocd app set <app> --sync-policy none`
3. `kubectl apply -f <hotfix-manifest>` (record the SHA in audit chain)
4. PR raised within 24h to commit the same change to `main`
5. Re-enable auto-sync once PR merges: `argocd app set <app> --auto-prune --sync-policy automated`

**Without CISO sign-off, do not bypass GitOps.** ArgoCD will revert manual changes within the next sync window.

## Validation gate (T3-P4)

- `argocd app list` shows all 11 child apps `Healthy + Synced`
- Deploy a no-op PR to `main`; ArgoCD detects change + syncs within 3min
- Drift test: `kubectl scale deployment bff --replicas=999` → ArgoCD reverts within 2min

## Rollback

```bash
# Disable auto-sync on every child app
for app in $(argocd app list -o name); do argocd app set $app --sync-policy none; done

# Manual fallback: apply from infra/k8s/ directly
kubectl apply -f infra/k8s/deployments.yaml
kubectl apply -f infra/k8s/serviceaccounts.yaml
# ...etc
```
